# Settings inventory

Generated by `scripts/settings_inventory.py` (plan task T2.1).
Do not edit by hand: run `scripts/settings_inventory.py --write`.
`SettingsInventoryCompletenessTest` runs `--check`, so adding a
prefs file or a Room database without regenerating turns CI red.

Not derived here, on purpose: per-key defaults and writer/reader sets
(that is dataflow, not a scan), and the `Natives.get*/set*` surface
(358 methods whose setting/data/command split needs a human pass).

`Defined in` names one file that declares a constant resolving to that
prefs file (the first alphabetically, so the doc is reproducible); a name
may be declared in several places.
